# Модуль «оркестратор»

Съёмная надстройка над базовым `template/`: даёт агенту способность самому
создавать суб-агентов (отделы) и консультироваться с ними. Не входит в
обычную установку — накатывается только когда агенту это реально нужно,
кем угодно на любом уровне (главным агентом клиента или позже — любым его
суб-агентом, который сам вырос в отдел).

## Когда накатывать

Не по умолчанию всем. Только когда агент явно будет строить/координировать
своих суб-агентов — решается на онбординге (вопрос «будешь координировать
других агентов?») или позже, в любой момент, когда реальная задача это
показала.

## Как накатывать

```bash
./become-orchestrator.sh /путь/к/папке/агента
```

Добавляет: `agents/_template/` (облегчённый шаблон суб-агента, без
онбординга/USER.md — профиль пользователя суб-агент берёт по ссылке на
уровень выше), скилл `.claude/skills/spawn-subagent/`, скрипт
`scripts/ask_colleague.mjs`, и дописывает в `MEMORY.md` два раздела («Что я
строю», «Собранные суб-агенты») — только если их там ещё нет.

## Что внутри

- `agents/_template/` — AGENTS.md/CLAUDE.md/SOUL.md/GOALS.md/MEMORY.md +
  замки безопасности, тот же принцип, что в основном ките, но без
  онбординга/house-tour (суб-агент не знакомится с человеком заново). Суб-агент
  читает свой `MEMORY.md` (по своей теме) и вдобавок общий `../../MEMORY.md`
  оркестратора (факты про всего клиента) — только читает, не пишет туда:
  нашёл что-то общее — предлагает оркестратору занести самому.
- `.claude/skills/spawn-subagent/` — адаптация `/new-agent` из `agent_katya`:
  собирает роль, allow-list скиллов, правила консультаций, цель — и создаёт
  `agents/<имя>/` из шаблона.
- `scripts/ask_colleague.mjs` — вызов другого суб-агента с вопросом,
  неинтерактивно, с таймаутом 120 сек. Специально **без**
  `--dangerously-skip-permissions` — консультация это вопрос-ответ, не
  выполнение действий, замки целевого суб-агента не обходятся.

## Вложенность отделов

Способность создавать суб-агентов не привязана к «главному» уровню — это
съёмный модуль, который можно накатить и на суб-агента, если у него самого
появится своя команда. Так глубина дерева решается по факту необходимости,
а не жёстким архитектурным потолком.
