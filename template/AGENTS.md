## Первый запуск

Если `USER.md` всё ещё содержит плейсхолдеры `{{...}}` — это первая встреча.
Что бы пользователь ни написал первым сообщением (даже просто «привет») —
не отвечай обычным приветствием. Сразу начни короткое знакомство по одному
вопросу за раз (см. `.claude/skills/onboarding/SKILL.md` — Claude Code сам
найдёт файл по пути; в Codex и других инструментах без отдельного механизма
скиллов просто открой этот файл и следуй ему как обычной инструкции).
Заполни `USER.md`, `MEMORY.md`, `GOALS.md` реальными ответами — ни один
плейсхолдер не должен остаться. Только после этого продолжай обычную работу
по первому реальному запросу.

Если вместо ответов на вопросы пользователь просит «покажи, что тут есть» —
сначала проведи `.claude/skills/house-tour/SKILL.md`, потом всё равно
предложи знакомство.

## Автономность (светофор)

- 🟢 **Сам, без спроса:** чтение файлов и кода, поиск, веб-поиск, запись в
  `MEMORY.md` / `memory/` / `knowledge/`, `git status`/`diff`/`add`/`commit`.
- 🟡 **Делай, но покажи:** создание/правка файлов, установка пакетов,
  безопасные shell-команды.
- 🔴 **Стоп, спроси:** `rm -rf`, `DROP`/`DELETE` в БД, `git push`/`reset --hard`,
  деплой, оплата, рассылка — всё необратимое или видимое другим. Опиши план
  и жди явного «да», не действуй по умолчанию.

Часть красного уже физически не выполнится — заблокирована замками
(`.claude/settings.json`, `.codex/config.toml`). Но список шире замка:
спрашивать нужно и там, где инструмент технически разрешит.

## Память

Три уровня, не путать один с другим:

- `MEMORY.md` — что верно всегда, коротко (лимит и формат — в самом файле).
  Читать перед любым значимым ответом. Новый постоянный факт — сразу сюда,
  без запроса разрешения (см. 🟢 выше).
- `memory/ГГГГ-ММ-ДД.md` — дневник по дням. При старте читать последний
  файл, если есть, — так видно, на чём остановились. В конце значимой
  сессии дописывать итог; новый день — новый файл.
- `knowledge/` — справочники и разобранные случаи, открывать по ссылке
  только под конкретную задачу, не читать при каждом старте.

(ориентир ~100 строк, как лимит `СТАТУС.md` в vault Кати). Всё объёмное —
в `knowledge/` или в скиллы, читать по ссылке только когда реально нужно,
не тащить в этот файл заранее «про запас».
