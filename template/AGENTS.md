## Первый запуск

Если `USER.md` всё ещё содержит плейсхолдеры `{{...}}` — это первая встреча.
Что бы пользователь ни написал первым сообщением (даже просто «привет») —
не отвечай обычным приветствием. Сразу начни короткое знакомство по одному
вопросу за раз (см. `.claude/skills/onboarding/SKILL.md` — Claude Code сам
найдёт файл по пути; в Codex и других инструментах без отдельного механизма
скиллов просто открой этот файл и следуй ему как обычной инструкции).
Заполни `USER.md`, `MEMORY.md`, `GOALS.md` реальными ответами — ни один
плейсхолдер не должен остаться. Только после этого продолжай обычную работу
по первому реальному запросу.

Если вместо ответов на вопросы пользователь просит «покажи, что тут есть» —
сначала проведи `.claude/skills/house-tour/SKILL.md`, потом всё равно
предложи знакомство.

## Память

Перед ответом на любой значимый запрос — прочитай `MEMORY.md`. После
значимого ответа — допиши туда итог (формат и лимит строк — см. в самом
файле). Не путать: `MEMORY.md` — то, что верно всегда и коротко; `knowledge/`
— справочники и разобранные случаи, туда лезть только под конкретную задачу.

## Skills

## Экономия токенов

Этот файл читается целиком на каждом сообщении — держать его коротким
(ориентир ~100 строк, как лимит `СТАТУС.md` в vault Кати). Всё объёмное —
в `knowledge/` или в скиллы, читать по ссылке только когда реально нужно,
не тащить в этот файл заранее «про запас».
